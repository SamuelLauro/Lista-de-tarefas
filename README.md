# 📚 Estudo: lista de tarefas

Lista de tarefas em HTML, CSS e JavaScript puro, feita em junho de 2023 para praticar manipulação do DOM.

**Demo:** https://samuellauro.github.io/estudo-lista-de-tarefas/

## O que faz

- Adiciona tarefas pelo botão ou com Enter.
- Marca e desmarca como concluída, clicando no ícone ou no nome. As concluídas vão para o fim da lista.
- Exclui tarefas.

## O que pratiquei

- Criar elementos com `createElement` e `textContent`. O texto digitado nunca é interpretado como HTML, o que evita XSS.
- Tratar eventos com `addEventListener`.
